Personal-style chatbot

Fine-tuning pipeline · private dataset

An end-to-end pipeline that turns a personal message archive into a chat-format training set, fine-tunes a small Llama model on it with QLoRA, and serves the result locally behind a web UI that imitates a phone messaging app.

  • Parser strips tapbacks, attachments and link previews, then merges consecutive messages into turns
  • Sliding three-turn context window over 212 conversations yields 3,050 instruction pairs, split 90/10
  • 4-bit QLoRA on Llama-3.2-3B-Instruct via Unsloth and PEFT; served by FastAPI with the adapter loaded at runtime
The dataset is private personal correspondence. It is never published, never committed, and stays on one machine — only the code and the method are shared.
