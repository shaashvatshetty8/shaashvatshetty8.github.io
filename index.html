Featured research

Profiling and pruning visual-token KV caches

CRA-WP DREU, Summer 2026 — University of Maryland, advised by Prof. Bahar Asgari. Continuing as an independent study.

Qwen2.5-VL-3B PyTorch CUDA / Triton Hugging Face UMIACS Nexus cluster

Does a text-only pruning rule survive contact with images?

A vision-language model turns one page of a document into more than a thousand visual tokens, and every one of them adds a Key and a Value entry at every layer. At that point the cache, not the weights, is what you are paying for. Pruning methods like Mustafar shrink text caches by dropping small-magnitude elements — but nobody had checked whether a visual token's cache has the structure that rule depends on.

Finding. Visual Key caches carry the same layer-wise outlier-channel concentration as text Key caches, at comparable magnitude. There is no separate "visual regime" — the premise behind text-only magnitude pruning holds for visual tokens too.
Open problem. The memory win is real and measured. The speed win is not: the vendored CUDA kernel is correct on 500 examples per dataset, but 5–7× slower than FlashAttention-2 at this model's narrow 16-query / 2-KV-head geometry. Stated plainly rather than worked around.

Personal-style chatbot

Fine-tuning pipeline · private dataset

An end-to-end pipeline that turns a personal message archive into a chat-format training set, fine-tunes a small Llama model on it with QLoRA, and serves the result locally behind a web UI that imitates a phone messaging app.

  • Parser strips tapbacks, attachments and link previews, then merges consecutive messages into turns
  • Sliding three-turn context window yields roughly 3,000 instruction pairs with a 90/10 split
  • 4-bit QLoRA on Llama-3.2-3B-Instruct via Unsloth and PEFT; served by FastAPI with the adapter loaded at runtime
The dataset is private personal correspondence. It is never published, never committed, and stays on one machine — only the code and the method are shared.

DREU research · 2026

The research thread above, as an engineering artefact: a bitmap-compressed KV cache for Qwen2.5-VL that reports its own real byte count while the model generates.

About

A bit more context

I'm at the University of Maryland finishing dual bachelor's degrees in Computer Science and Statistics, graduating in December 2026. The statistics half is not decoration. Most of what I enjoy about systems work is the measurement: building a controlled comparison, holding the confounds still, and letting the result say what it says even when that is inconvenient.

That shows up in the research. My DREU project could have reported a memory win and stopped there. Instead it reports the memory win and a kernel that turned out slower than the baseline it was supposed to beat, because the second result is the one that tells you where to work next.

Coursework worth naming: advanced data structures, algorithms, data science and machine learning, computer systems, domain-specific architectures, generative AI agents, and applied probability and statistics.

Away from a terminal I swim, play chess, and practise Bharatanatyam, a classical Indian dance form that has taught me more about precision under pressure than any debugger has.
